# Evidence attachments

This directory is reserved for small, versioned data and figures supporting bottleneck findings that pass the issue evidence criteria. No performance attachments are selected at this preparation stage. The complete original investigation and review bundle remain intact in the workspace identified by the provenance manifest.

Keep request-level sources, units, timing boundaries, run mode, hashes, and figure-generation code with any future eligible attachment. Do not place model weights, audio files, virtual environments, full logs, or large profiler traces here.
